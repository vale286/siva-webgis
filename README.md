# SIVA - Geospatial Intelligence Dashboard

## Project Overview

SIVA (Sihanouk Intelligence and Vulnerability Analysis) is a modern, data-driven web application designed to map, analyze, and mitigate the risks of human trafficking and organized crime networks in Southeast Asia, with a primary focus on Sihanoukville, Cambodia.

This project was developed by **Baptista Yohana Vallen** as part of the assignment for the **Kapita Selekta Sistem Informasi** course at **Universitas Bakrie** (2026).

## Key Features

1. **Vulnerability Analysis:** Spatial mapping to correlate poverty metrics with exploitation risks.
2. **Scam Hotspot Identification:** Identification of closed complexes and high-risk cyber operation zones.
3. **Transit to Trap Mapping:** Visualization of logistical corridors and transit movements used by smuggling syndicates.
4. **Escape & Rescue Routes:** Planning and mapping of safe zones, diplomatic facilities, and evacuation routes.
5. **SIVA AI Chatbot:** An integrated, intelligent assistant designed to provide interactive education on human trafficking schemes and emergency survival protocols.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Mapping:** Leaflet & React-Leaflet
- **Spatial Analysis:** Turf.js
- **Icons:** Lucide React

## Academic Context

This system serves as a proof-of-concept for applying Information Systems and Geospatial Intelligence to solve pressing global humanitarian crises. It demonstrates the integration of spatial data visualization with interactive web technologies to deliver actionable intelligence.

## Getting Started

To run this project locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the dashboard.
